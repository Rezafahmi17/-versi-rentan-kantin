# -versi-rentan-kantin

Projek simulasi website kantin kampus versi rentan untuk praktikum Keamanan Sistem Informasi (KSI).

## Deskripsi
Aplikasi web berbasis HTML/JavaScript yang mensimulasikan asisten kantin berbasis AI dengan kerentanan keamanan (seperti prompt injection dan penanganan API key sisi klien) untuk tujuan analisis dan pengujian keamanan sistem informasi.

## Berkas
- `kantin-rentan.html` : Halaman web simulasi asisten kantin versi rentan.
